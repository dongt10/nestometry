# Research Folder

Use this folder for source cards, missing-dimension lists, measurement plans, and public research notes that are suitable for version control. Keep private working references outside the repository.

Do not commit:

- proprietary virtual-tour screenshots
- personal student-room photos
- restricted drawings
- sensitive building details

Every source-backed claim should eventually become either:

- a source-card fact in `packages/berkeley-data/source-ledger/`
- a JSON schema field in `packages/berkeley-data/halls/`
- a QA note in `reports/qa/`
