# Dorm Measurement Checklist

Use only with authorization and in unoccupied/private-safe spaces.

## Room shell

- Wall-to-wall width
- Wall-to-wall depth
- Floor-to-ceiling height
- Door width
- Door height
- Door swing direction
- Door position from nearest corner
- Window width
- Window height
- Window sill height
- Window position from nearest corner
- Built-in closet width/depth/height
- Radiator/HVAC unit size and position, if visible and not sensitive
- Outlets, only if useful for planning and not sensitive

## Furniture

- Twin XL bed frame width/depth/height
- Mattress height
- Loft bed clearance
- Bunk bed total height
- Desk width/depth/height
- Chair footprint
- Dresser width/depth/height
- Microchill width/depth/height
- Wardrobe/closet dimensions
- Bookshelf dimensions

## Photos for visual reference

- Empty room only, or remove personal items
- Corner-to-corner photos
- Door wall
- Window wall
- Furniture closeups
- Ceiling/floor material

## Required notes

- Date measured
- Measured by
- Device/method
- Room type
- Whether room is representative or room-specific
- Permission basis
